# Prompts para Gemini Flash 3.5 (Imagen 3)

Este archivo contiene prompts **específicamente adaptados** para generar imágenes de testimonios utilizando **Google Gemini Flash 3.5** (con el modelo de generación de imágenes Imagen 3).

## ¿Por qué una versión específica para Gemini?

Los prompts optimizados para Midjourney o Flux no funcionan de forma óptima en Gemini. 

Esta versión ha sido reescrita siguiendo las mejores prácticas para **Imagen 3**, con las siguientes características:

- Lenguaje más natural y descriptivo.
- Eliminación de parámetros técnicos de otras herramientas (`--ar`, `--v`, `--stylize`, etc.).
- Mayor énfasis en realismo fotográfico, iluminación y calidad.
- Estructura clara y efectiva que Gemini entiende mejor.

---

## Recomendaciones de uso en Gemini Flash 3.5

1. Copia el prompt completo y pégalo en Gemini.
2. Puedes añadir al final frases como:
   - `High resolution, photorealistic, professional photography`
   - `8k detail, natural skin texture`
3. Si quieres variaciones, puedes modificar ligeramente la ropa o el fondo manteniendo el resto del prompt.
4. Para mejores resultados, genera varias versiones y elige la que tenga mejor expresión y mirada.

## Consejos adicionales para Gemini Flash 3.5

- Si la imagen sale demasiado formal, añade al final: `warm and approachable expression`.
- Si quieres un fondo más neutro, añade: `plain light gray background` o `soft beige background`.
- Para mayor realismo, puedes incluir: `shot on 85mm lens, shallow depth of field`.
- Gemini suele dar mejores resultados cuando el prompt es claro y bien estructurado. Evita ser demasiado poético.

# Prompts para generar imágenes de testimonios

Este documento contiene prompts optimizados para generar fotos profesionales de emprendedores hispanohablantes para la sección de testimonios del sitio.

**Recomendación de estilo general (usa este prefijo en todos los prompts):**

```
Professional headshot of a [edad] year old [nacionalidad] entrepreneur, friendly and trustworthy expression, natural smile, soft natural lighting, clean modern background, high quality, realistic photography, 50mm lens, sharp details, business casual attire, confident and approachable look --ar 1:1 --v 6
```

## Notas importantes

- Todos los prompts están optimizados para **Midjourney v6**, **Flux**, o **Leonardo AI**.
- Usa `--ar 1:1` para que las imágenes sean cuadradas (ideal para tarjetas de testimonios).
- Si quieres un estilo más cálido y cercano, añade al final: `warm tones, approachable`.
- Si prefieres un look más corporativo: `professional studio lighting, clean white background`.
- Guarda las imágenes finales en:
  ```
  /public/images/testimonials/
  ```
  con nombres descriptivos como:
  - `carlos-mendoza-valencia.webp`
  - `sofia-ramirez-buenos-aires.webp`

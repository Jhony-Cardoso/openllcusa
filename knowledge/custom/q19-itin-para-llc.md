# ¿Qué es el ITIN y lo necesito como propietario de una LLC?

El **ITIN** (Individual Taxpayer Identification Number) es un número de identificación fiscal personal emitido por el IRS para individuos que no son elegibles para obtener un SSN (Social Security Number). Tiene el formato W-XXXXXXX.

## ¿Cuándo necesitas el ITIN?
- Para presentar tu **declaración personal de impuestos** en EE.UU. (si aplica a tu situación).
- Para reclamar beneficios de **convenios de doble imposición** con EE.UU.
- Para abrir ciertos tipos de **cuentas bancarias** en bancos tradicionales americanos.
- Para algunas plataformas de pago o marketplaces que lo soliciten.

## ¿Lo necesitas para registrar la LLC o el EIN?
**No necesariamente.** El EIN puede obtenerse enviando el Formulario SS-4 por correo o fax sin necesitar ITIN ni SSN, aunque el proceso tarda más. Si tienes ITIN, el proceso es más ágil.

## ¿Cómo se obtiene el ITIN?
Se solicita al IRS mediante el Formulario W-7, generalmente adjunto a tu primera declaración de impuestos. El proceso puede tardar entre 7 y 11 semanas. Se puede hacer por correo o a través de un CAA (Certifying Acceptance Agent).

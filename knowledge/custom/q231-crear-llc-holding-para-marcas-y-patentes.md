# ¿Debo crear una LLC separada solo para poseer mis Marcas y Patentes?

En estructuras avanzadas, los grandes e-commerces crean una "IP Holding LLC" (una LLC que no vende nada, solo posee las patentes, el software y las marcas). Esta LLC le "licencia" el derecho de uso a la "Operating LLC" (la LLC que hace las ventas y corre riesgos). Si la Operating LLC es demandada por un producto defectuoso y embargada, el demandante no podrá tocar ni las patentes ni la marca, ya que pertenecen a la IP Holding LLC.

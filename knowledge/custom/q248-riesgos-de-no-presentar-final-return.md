# ¿Qué pasa si disuelvo la LLC en el estado pero olvido enviar el Final Return (5472) al IRS?

Este es un error que puede ser catastrófico. Si cierras la LLC pero el IRS no procesa el "Final Return", su sistema asumirá que la LLC sigue activa y esperará el Formulario 5472 al año siguiente. Si no lo envías, generarán automáticamente la multa de $25,000. Nunca debes olvidar cerrar la entidad a nivel federal con el IRS.

# ¿Puedo pagar mis suscripciones a software (ChatGPT, Canva, Adobe) con la LLC?

Sí, siempre que esas herramientas se utilicen para generar ingresos o administrar tu negocio. Si pagas el plan de Netflix familiar con la tarjeta de la LLC, estarás mezclando finanzas personales (Piercing the veil). Para el software de uso mixto (ej. un teléfono móvil), debes deducir solo el porcentaje que corresponda a uso comercial.
